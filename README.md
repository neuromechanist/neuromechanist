### Hi, I'm Yahya

**Assistant Project Scientist & Principal Investigator** at the [Swartz Center for Computational Neuroscience](https://sccn.ucsd.edu), UC San Diego

I develop open-source tools for biosignal analysis and contribute to neuroinformatics standards. My research integrates computational neuroscience with human cognition and behavior, focusing on EEG/EMG signal processing, neuroinformatics infrastructure, and the neural control of movement.

#### Open-Source Tools

**Standards & Infrastructure**
- [EMG-BIDS Extension](https://github.com/bids-standard/bids-specification/pull/1998) - Extending BIDS for EMG and high-density EMG data
- [Stim-BIDS Extension](https://github.com/bids-standard/bids-specification/pull/2022) - Standardizing stimulus presentation and annotation

**Signal Processing**
- [emg2mu](https://github.com/neuromechanist/emg2mu) - PyTorch-accelerated EMG decomposition
- [emgio](https://github.com/neuromechanist/emgio) - Unified interface for EMG data formats
- [hdEMG-Decomposition](https://github.com/neuromechanist/hdEMG-Decomposition) - ICA decomposition for high-density sEMG

**AI/LLM Integration**
- [MATLAB-MCP](https://github.com/neuromechanist/matlab-mcp-tools) - Model Context Protocol for MATLAB
- [HED-MCP](https://github.com/hed-standard/hed-mcp) - MCP implementation for HED annotations
